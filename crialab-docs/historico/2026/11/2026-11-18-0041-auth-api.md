# Auth da API

- **Data:** 2026-11-18 00:41 (America/Sao_Paulo)
- **Tipo:** feat

## Resumo

A API expõe cadastrar, entrar, sair, renovar e eu com Identity, papéis `Usuario`/`Administrador`, JWT curto e refresh em cookie HttpOnly.

## Decisões

- Regras de senha iguais à decisão 6: dígito, minúscula, maiúscula, não alfanumérico, mínimo 8, sem confirmação de e-mail.
- Cadastro público recebe `Usuario`. Admin do seed entra com `Administrador` e `Usuario`.
- Refresh fica em cookie `crialab_refresh`; access token no corpo da sessão.

## O que foi feito

- Handlers e validadores em Application; Identity + emissor JWT em Infrastructure.
- `ModuloAuth` com `/api/auth/cadastrar`, `/entrar`, `/sair`, `/renovar`, `/eu`.
- `AuthTests` cobrindo fluxo completo e login do administrador do seed.
