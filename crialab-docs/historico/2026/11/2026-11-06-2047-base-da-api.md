# Base da API

- **Data:** 2026-11-06 20:47 (America/Sao_Paulo)
- **Tipo:** feat

## Resumo

A API passou a registrar Carter, EF Core com Npgsql, snake_case, Identity, Dapper, FluentValidation, Problem Details e OpenAPI. O Razor não mudou de comportamento.

## Decisões

- As regras de senha e a conta sem confirmação de e-mail repetem o `Program.cs` do Razor. O login por cookie do Razor não entra: a sessão da API continua sendo JWT e refresh cookie, no item de auth.
- As tabelas do Identity recebem os mesmos nomes em snake_case do `OnModelCreating` do Razor, porque a convenção não reescreve nome definido pelo Identity.
- A política `AdminOnly` existe. Aplicá-la nos módulos administrativos continua no item próprio.
- O pipeline que transforma exceção em Problem Details em português, o health check e o `docker-compose` continuam abertos.

## O que foi feito

- Usuário da aplicação com nome, data, telefone e documento.
- Contexto EF, leitor Dapper e validadores da Application registrados.
- `GET /openapi/v1.json` coberto por teste, junto com senha, política, Problem Details, módulo Carter e coluna `nome_completo`.
