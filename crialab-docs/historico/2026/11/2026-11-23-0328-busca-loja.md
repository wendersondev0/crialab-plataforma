# Busca da loja

- **Data:** 2026-11-23 03:28 (America/Sao_Paulo)
- **Tipo:** feat

## Resumo

A busca da vitrine passou para a API e para a tela Vue em `/busca`, com os mesmos filtros, sugestões, chips e ordenação da página Razor.

## Decisões

- A lista publicada sai do Dapper. Texto, preço, nota, flags, ordenação e chips ficam no Domain.
- O prazo continua como dados. A tela monta a frase e, no personalizado, mostra “Preço médio · fecha no orçamento”.
- A ficha do produto ainda não existe. A sugestão aponta para `/produto/:id`, que entra no próximo item da lista.

## O que foi feito

- `GET /api/loja/busca` e `GET /api/loja/busca/sugestoes`, públicos, com o mesmo conteúdo para anônimo, usuário e administrador.
- Sem filtro, a resposta traz as 8 peças publicadas. Chips removem a chave da URL. Preço invertido é avisado e trocado.
- Tela Vue com painel, sugestões, chips, vazio, erro e uma coluna no celular. A home ganhou o atalho Busca.
