# Prazo de vitrine no Domain

- **Data:** 2026-11-23 02:55 (America/Sao_Paulo)
- **Tipo:** feat

## Resumo

O prazo da vitrine passou para `CriaLab.Domain` como dados. O Vue monta a frase. A API não devolve HTML.

## Decisões

- Personalizado devolve só o número de dias (padrão 5). Sob demanda e pronta entrega devolvem início e fim, com a mesma conta de `LojaVitrineHelper`.
- Frete grátis é o preço maior ou igual ao limite da loja. No personalizado a frase continua sendo “prazo após orçamento”, então o tipo é `apos-orcamento`.

## O que foi feito

- `Calculos/PrazoVitrine.cs`.
- Seis testes verdes: personalizado, prazo padrão, sob demanda, pronta entrega, PAC curto e frete grátis pelo preço.
