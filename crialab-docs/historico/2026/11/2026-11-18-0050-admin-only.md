# Guarda AdminOnly

- **Data:** 2026-11-18 00:50 (America/Sao_Paulo)
- **Tipo:** feat

## Resumo

Os módulos administrativos passam a entrar pelo grupo `/api/admin` com a política `AdminOnly`. Anônimo recebe 401, `Usuario` recebe 403 e `Administrador` passa.

## Decisões

- `MapGrupoAdmin` concentra a guarda; os módulos admin futuros reutilizam esse grupo.
- JWT usa claim `role` curta, com `MapInboundClaims = false`, para o `RequireRole` bater com o papel `Administrador`.
- `GET /api/admin/acesso` serve de âncora da guarda enquanto as telas admin ainda não existem.

- `ModuloAdminAcesso` e teste `AdminOnlyTests` com os três perfis da seção 8.
