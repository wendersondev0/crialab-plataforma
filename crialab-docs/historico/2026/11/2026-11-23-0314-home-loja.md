# Home da loja

- **Data:** 2026-11-23 03:14 (America/Sao_Paulo)
- **Tipo:** feat

## Resumo

A home passou a existir na API e no Vue: identidade, modalidades, temas, peças publicadas, depoimentos e parceiros que podem aparecer.

## Decisões

- A leitura usa Dapper. O prazo da vitrine vai como dados, e a tela monta a frase.
- Depoimento com `PodeAparecer` falso fica de fora. O Razor não desenha depoimento na home; o plano pede essa seção, então ela entrou aqui.
- O texto do menu de ajuda `inicio` aparece junto da frase que a view Razor já mostra.

## O que foi feito

- `GET /api/loja/home`, público, com o mesmo conteúdo para anônimo, usuário e administrador.
- Tela Vue em `/`, com carregando, erro, vazio e grade em uma coluna no celular.
- Dois testes da API verdes. No navegador: carrossel, fotos, parceiros, depoimento da Mileni, erro ao cair a API e retorno pelo botão tentar de novo.
