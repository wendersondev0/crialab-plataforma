## Histórico

Cada alteração relevante vira um arquivo. Os arquivos ficam agrupados por ano e mês:

```
historico/AAAA/MM/AAAA-MM-DD-HHmm-titulo-kebab.md
```

- Data e hora em `America/Sao_Paulo`.
- O nome do arquivo é a data, a hora e um título curto, sem acentos.
- O arquivo traz o que foi feito, o porquê e as decisões que não devem ser reabertas.

O índice em `historico/INDEX.md` lista do mais recente para o mais antigo.
