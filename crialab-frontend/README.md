# Cria Lab — frontend

PWA em Vue 3, TypeScript, Vite, PrimeVue, Pinia e Vue Router.

A home (`/`) lê `GET /api/loja/home` pelo proxy do Vite. A API precisa estar em `http://localhost:5080`.

```powershell
npm install
npm run dev
```

O manifesto, o service worker e a instalação ficam para a fase de PWA do plano.

Plano: [../crialab-docs/planejamento/conversao-razor-para-vue-api.md](../crialab-docs/planejamento/conversao-razor-para-vue-api.md).
