# Página para gerenciar papéis de acesso

- **Versão:** v006
- **Data:** 2026-10-28 17:10 (America/Sao_Paulo)
- **Tipo:** feat

## Resumo

A administração ganhou a tela Papéis em `/Admin/Papeis`. Dá para criar um papel, ver quem tem cada um e marcar ou desmarcar por pessoa. Os nomes gravados continuam `Usuario` e `Administrador`.

## Decisões técnicas

- A tela mostra "Usuário" e "Administrador". A autorização segue olhando as strings gravadas no Identity.
- Papéis do sistema não podem ser apagados. Um papel com gente atribuída também não, até ser retirado.
- A pessoa logada não tira Administrador da própria conta, e a oficina não fica sem nenhum Administrador.
- O CSS de aviso (`.cta-ok` / `.cta-erro`) entrou no `admin.css`, porque o layout da administração não carrega a vitrine.
- Não há página estática equivalente. O menu do HTML de referência não ganhou um link quebrado; só o CSS foi espelhado.

## Funcionalidades / comportamento

- Criar papel (2 a 40 letras ou números; espaço, hífen ou _).
- Nome repetido é recusado.
- Cada pessoa tem caixas dos papéis existentes e um Salvar.
- Apagar só o papel que não é do sistema e que não está em ninguém.
- Atalho no painel e no menu, com Papéis ativo nessa rota.
